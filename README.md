# SpendSmart — Frontend Demo

A responsive credit-card and expense-management dashboard built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser. For best results, use VS Code with the Live Server extension.
3. Sign in with:
   - Email: `demo@spendsmart.in`
   - Password: `demo123`

No backend or database is included. Data is stored in the browser using LocalStorage.

## Files
- `index.html` — app structure and all page sections
- `style.css` — responsive fintech UI
- `script.js` — demo data, LocalStorage, calculations, charts and interactions

## Features
Dashboard, cards CRUD, expense CRUD and CSV export, bill tracking, rewards, reward comparison, spending insights, family demo view, security-awareness report form, profile/preferences/budget settings, notifications, and responsive navigation.

## Important limitations
This is a college-project frontend demonstration, not a real financial service. Authentication is client-side and is not secure. Never enter real credentials or sensitive card information. No real payment, bank connection, fraud report, or multi-user access is performed. Reward rates are illustrative estimates and do not represent issuer offers.

Chart.js and Font Awesome are loaded from CDNs, and Google Fonts are loaded online. An internet connection is needed for those external assets; core layout and functionality run locally.
